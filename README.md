# Коррекция фотографий на основе ИИ

Локальная коррекция фотографий в браузере: яркость, контраст, цветность. ИИ подбирает параметры для каждого фото отдельно.

## Быстрый старт

1. Создайте свой репозиторий на GitHub (например, `pro-it-tech`)
2. Смените remote и запушьте:
   ```bash
   git remote set-url origin https://github.com/YOUR_USERNAME/pro-it-tech.git
   git push -u origin main
   ```
3. Добавьте секреты в GitHub (см. [DEPLOY.md](DEPLOY.md))
4. Выполните деплой Worker: `cd worker && npx wrangler deploy`
