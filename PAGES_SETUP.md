# Настройка GitHub Pages

## Вариант 1: Деплой из ветки (проще)

1. Откройте: https://github.com/krivetka13011/pro-it-tech/settings/pages
2. **Build and deployment** → **Source**: выберите **Deploy from a branch**
3. **Branch**: `main` / **Folder**: `/ (root)`
4. **Save**

Сайт: https://krivetka13011.github.io/pro-it-tech/

---

## Вариант 2: GitHub Actions

Если Source уже **GitHub Actions** — workflow должен работать. Проверьте: **Actions** → последний запуск.
